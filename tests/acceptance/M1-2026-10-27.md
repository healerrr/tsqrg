# M1 操作与美术方向验收记录

日期：2026-10-27（Asia/Shanghai）。环境：Windows 10.0.19045 x64、Node.js 24.12.0、pnpm 9.15.5、规则 1.0.0。浏览器：Edge 131.0.2903.86、Chrome 155.0.8059.86，均使用本机安装版并以无头 SwiftShader WebGL 执行。目录当时没有 Git 仓库，故没有可记录的 commit。

实际命令：

```powershell
$env:AQUARIUM_E2E_REPORT='artifacts/m1/e2e-results.json'
pnpm exec playwright test -c tests/e2e/playwright.config.ts --grep M1 --output artifacts/m1/e2e
```

最终结果：**10 项通过，0 项失败，用时 3.4 分钟**。每个浏览器各执行五项：

- 六个可辨认鱼型为独立实体；键盘产生实际世界位移；冲刺入口可操作；窗口失焦后清除输入并停止游动。
- 打开面板后方向键和空格不会操控鱼；金鱼、小丑鱼、河豚、斗鱼、神仙鱼、鳐鱼均能切换，调试读数反映真实渲染鱼型。
- 1280×720、844×390、390×844 三个视口的水面点按产生实际游动，冲刺按钮可见，面板宽度不越过视口。
